GitHub에 압축을 푼 파일을 업로드/덮어쓰기한 후 배포하고 새로고침해주세요. 추가 SQL 없습니다.

실행가를 새로 생성한 다음, 요율을 입력하고 Excel에서 저장한 파일로 신청서도 다시 생성해주세요.

수정 내용
- 개별단가는 기본 빈 양식 또는 첨부 양식의 잘못된 표 머리글 대신, 기존 휘경미소지움 개별단가 전용 서식을 사용합니다.
- 항목/위치/제품명/유리사양/금액 머리글과 외창·내창 행 색상 및 행 높이를 복원합니다.
- 유리 사양은 외창/내창 및 고정창 두께에 맞춰 읽기 쉬운 문구로 표시합니다.
- 외창/전체창 합계에 (1~번호) 범위를 표시합니다.
- F열 E×0.85, 10만원 단위 반올림 유지.
- 개별단가 인쇄 영역 A:F 및 영역 밖 번호 그림 유지.
- 신청서는 합계 라벨의 번호 범위, 외창/내창 구분, 합계 수식을 교차 확인합니다.
- 기존 파일에서 H열이 85% 계산용인 경우 이를 외창 구분으로 오인하지 않습니다.
- 구분을 확인할 수 없거나 서로 다른 경우 생성을 중단해 안내하며, 임의로 '외부창 없음'을 표시하지 않습니다.

첨부 실행가에는 요율/금액 계산값이 비어 있어 번호 검증에는 첨부 신청서의 금액을 시험용으로 사용했습니다. 견적 금액을 임의 입력하거나 원본 파일을 수정하지 않았습니다.
실행가 생성 검증은 별도 본사 자료로 수행했습니다. Microsoft Excel 실제 열기/인쇄는 배포 후 확인해주세요.
