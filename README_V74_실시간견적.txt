V74 실시간 견적 워크스페이스

왼쪽 메뉴: PC에서 마우스를 올리면 메뉴명이 펼쳐집니다. 고정 버튼으로 펼친 상태를 유지할 수 있습니다.
모바일에서는 상단 메뉴 버튼으로 열고, 바깥 영역 또는 Esc 키로 닫습니다.

실시간 견적: 견적 작성·수정 중 규격, 제품, 요율, 부가시공비 조건, 추가상품 변경을 반영합니다.
PC에서는 오른쪽 요약을 유지하고, 767px 이하에서는 화면 하단 고정바로 표시합니다.
모바일 상세 보기를 누르면 항목별 금액이 펼쳐집니다.
미완성 항목이 있으면 임시 합계로 표시하며 저장 시 기존 필수 입력 검증을 수행합니다.

저장과 실시간 요약에서 부가시공비 공급가를 같은 기준으로 사용하도록 정리했습니다.
직접 입력한 요율도 저장과 미리보기에서 동일하게 적용합니다.

이 버전은 화면과 계산 연결 변경입니다. 추가 SQL 실행은 필요 없습니다.
기존 방식대로 GitHub 앱 파일을 교체한 후 브라우저를 새로고침해주세요.
