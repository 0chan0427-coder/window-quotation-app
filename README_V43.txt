DODO 창호 견적 관리 V43

V43 변경사항
- 창호 입력 카드의 실측 가로/세로 아래에 '요율(선택)' 입력칸 추가
- 요율 미입력 시 V42와 동일하게 현재 가격표 계산가 사용
- 요율 입력 시 현재 가격표의 자재비에 요율을 적용하고 시공비는 유지
- 요율은 견적별/창별로 저장되며 견적 수정 시 다시 입력·수정 가능
- 내부용 상세견적서에 창별 요율 표시
- 고객용 견적서에는 요율/내부 계산 정보 미표시
- 기존 추가상품, 할인/서비스, 결제조건, 고객 최종금액 수기조정 기능 유지

주의
현재 V43은 기존 V42 가격표 구조를 유지한 상태에서 창별 요율 기능을 추가한 테스트 버전입니다.
실행가 엑셀의 세부 원가 구성(K/L/M/N/O)을 그대로 재현하는 별도 원가 데이터가 없는 상태이므로,
요율 입력값은 현재 프로그램의 자재비 부분에 적용됩니다.
