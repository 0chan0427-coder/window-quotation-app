V66 실행가 엑셀 직접 입력

기존 GitHub 파일을 업로드/덮어쓰기하면 됩니다. 추가 SQL 없음. V64 행사 현황 SQL을 아직 적용하지 않았다면 기존 v64 SQL만 한 번 실행해주세요.

메인 순서: 행사 현황 → 실행가 엑셀 파일 생성 → 신청서 엑셀 파일 생성

실행가 생성:
1. 자재비·시공비 .xls/.xlsx를 여러 개 선택합니다. ZIP도 지원합니다.
2. 자료 분석 → 할인율/부가시공비 확인 → 모두 확인 → 생성. 요율은 비워둬도 됩니다.
3. 빈 양식은 앱에서 자동으로 사용하므로 별도 첨부 불필요.
4. 기존 양식을 사용하려면 .xlsx 양식 하나를 같은 파일 선택에 포함하거나 ZIP에 넣습니다. 기존 값을 가져옵니다. 양식은 한 개만 지원합니다.
5. 빈 양식 다운로드 기능도 유지합니다.

자료/양식 중복 선택 시 분석에서 오류를 안내합니다. 파일당 20MB, 선택 전체 60MB, 엑셀 최대 100개 지원.
V65 신청서와 V64 행사 현황 기능 유지.
