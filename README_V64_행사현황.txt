V64 행사 현황

적용 방법
1. Supabase > SQL Editor에서 supabase-migration-v64-events.sql 전체를 실행합니다. 기존 38개 행사가 등록되며 재실행해도 중복 등록되지 않습니다.
2. 압축을 풀고 기존 GitHub 저장소에 파일을 업로드/덮어씁니다. Vercel 배포 후 새로고침합니다.

메인 > 행사 현황
- 단지명, 담당자, 날짜, 행사 형태, 계약 건수/금액을 등록하고 행을 눌러 수정합니다.
- 계약금액 입력 및 표시 단위는 만원, 저장은 원입니다.
- 실적 빈칸과 0을 구분합니다.
- 연도/월, 직접 기간, 담당자, 단지명 검색 및 오름/내림 정렬. 날짜 조회와 월 집계는 시작일 기준입니다.
- 표와 월별 계약금액/건수 그래프는 조회 조건을 공유합니다.
- 팀 도넛 그래프는 기간/단지 조건의 팀 전체 금액을 100%로 하며 담당자 필터를 제외합니다.
- 한: 한동균 팀장 / 찬: 김민찬 책임 / 영: 김영찬 책임.
- 팀 공유 저장은 기존 담당자 선택 앱의 Supabase 접근 방식과 동일합니다. 담당자 선택은 사용자 인증이 아닙니다.
- V63 실행가 기능 유지.
