V52 변경사항

- 직접입력 창의 내부창/외부창 선택 UI를 더 명확하게 표시
- 기존 저장 견적을 수정할 때도 직접입력 창의 구분을 선택/저장 가능
- 기존 일반 창 종류는 window_scope를 자동 보정
- 기존 직접입력 창은 자동 추측하지 않고 수정 화면에서 사용자가 선택하도록 함
- 기존 견적 수정 시 실행가 default_rate를 새 요율로 자동 복원하지 않음
- 실제 저장된 pricing_rate가 있는 경우에만 요율을 유지
- 직접입력 창의 구분을 선택하기 전에는 부가시공비를 임시 안내하고, 저장 시에는 선택을 요구
