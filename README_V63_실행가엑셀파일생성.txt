1. GitHub에 적용하는 방법

압축을 풀고 window-quotation-app-v61-execution 폴더 안을 엽니다.
기존 GitHub 저장소에서 Add file > Upload files를 누릅니다.
아래 파일과 폴더를 기존 index.html이 있는 최상위 위치에 올립니다.

- index.html (교체)
- app.js (교체)
- execution-ui.js (추가)
- execution-engine.js (추가)
- execution.css (추가)
- vendor 폴더 전체 (추가: jszip.min.js, xlsx.full.min.js)
- assets 폴더 (기존 파일과 새 execution-blank-template.xlsx 포함)

Commit changes를 누르면 기존 GitHub/Vercel 연결로 배포됩니다.
바깥의 window-quotation-app-v61-execution 폴더 자체가 저장소 안에 생기지 않게,
그 안에 있는 파일과 vendor 폴더를 올려주세요.
SQL 실행, Supabase 설정 변경, Vercel 빌드 설정 변경은 필요하지 않습니다.
배포가 끝나면 PC는 Ctrl+F5로 새로고침하고, 모바일은 페이지를 다시 엽니다.
이 압축에는 기존 전체 소스도 들어 있으므로 전체 파일을 올리는 방식도 가능합니다.
supabase-config.js는 업로드받은 기존 값을 유지했습니다.

2. 사용 순서

담당자 선택 > 실행가 엑셀 파일 생성 > ZIP 선택 > 자료 분석

ZIP 구성:
- 실행가 원본 양식.xlsx 한 개
- 본사에서 내려받은 각 평형의 자재비.xls 또는 .xlsx
- 본사에서 내려받은 각 평형의 시공비.xls 또는 .xlsx

기존 프로그램이 만들어낸 실행가 결과 파일은 입력 ZIP에서 빼주세요.
평형은 파일명 또는 시트명에서 읽습니다. 예: 현장명_29평_자재비.xls
평형별로 자재비 표와 시공비 표가 각각 하나씩 필요합니다.
샘플의 원본 양식 구조(A12 설치위치, H12 수량, Q12 요율)를 지원합니다.
열 배치가 다른 양식은 설명과 함께 처리를 중단합니다.

자료 분석 후:
1) 각 평형의 할인율과 인상률을 확인합니다.
2) 장비비·철거비·타일·실측·몰딩·보양비를 확인합니다.
   외창만 교체하는 금액과 전체 교체하는 금액을 부가세 별도로 입력합니다.
   전체 금액에는 외창 금액이 포함됩니다.
   공통 ○평 양식에서는 부가시공비가 비어 있습니다. 미입력 비용은 0원으로 계산하고 Excel 입력칸은 비워둡니다.
3) 요율은 선택 입력입니다. 비워둔 채 생성한 뒤 Excel Q열에서 입력·수정할 수 있습니다.
   같은 요율을 미리 넣으려면 '전체 적용'을 누릅니다.
4) 시공비는 본사 원본의 창 제품 순번대로 자동 반영됩니다.
5) 평형별 확인 체크를 하고 '확인한 값으로 실행가 엑셀 생성'을 누릅니다.

3. 시공비 연결 규칙

자재비: 카테고리명·모형·틀짝망·형태명·유리스펙
시공비: 카테고리·제품명·틀짝망·창명·유리 제품명
이 정보가 일치하는 항목끼리 연결합니다.

자재비 유리의 '2-1'은 창 순번 1을 가리키고,
시공비 유리의 '1-1'은 창 순번 1의 하위 시공비입니다.
두 파일의 번호 표기 방식은 각각 해석하고, 연결된 유리의 규격과 형태도 확인합니다.

자재비와 시공비의 창 제품을 각각 원본 순번으로 정렬하고,
유리 행을 제외한 창 제품 순서대로 자동 연결합니다.
자재비 순번에 중간 번호가 빠져 있더라도 실제 존재하는 창 제품 순서로 처리합니다.
동일 순서의 제품·형태·틀짝망·유리스펙을 대조해서 연결을 검증합니다.
같은 제품에 서로 다른 금액이 있어도 원본 순번에 따라 자동 연결합니다.
제품 정보나 개수가 맞지 않으면 원본 파일과 순번을 표시하고 생성을 중단합니다.
시공비 직접 선택 단계는 없습니다.

4. 계산 기준

I: 완성창 판매단가, J: 유리 판매단가, H: 원본 창 수량
M: 연결된 창·유리 시공 판매금액 합계 / 원본 창 수량
K: I × (1 + 인상률 - 할인율), L: J

외창 부가시공비는 입력한 외창 금액을 배분합니다.
내창 부가시공비는 전체 금액에서 외창 금액을 뺀 차액을 배분합니다.
배분 비율은 각 창의 시공금액(M×H) / 해당 그룹 시공금액 합계입니다.
그룹 시공금액 합계가 0이면 원본 수량 비율로 배분합니다.
해당 그룹에 창이 없는데 비용이 입력돼 있으면 생성을 중단합니다.

DC 후 원가 U = (K+L)×H + (M×H+N+O)×1.1
DC 후 판매금액 V = (K+L)×H×요율 + (M×H+N+O)×1.1
창 행 판매금액 Z는 V를 만원 단위로 올림합니다.
AA는 Z를 기본으로 표시하며 Excel에서 수정할 수 있습니다.
요율이 비어 있으면 Q열은 실제 빈칸으로 저장합니다.
요율을 입력하기 전에는 해당 창의 판매금액과 마진이 빈칸으로 표시됩니다.
외창·내창 합계는 그 그룹의 요율을 모두 입력했을 때, 전체 합계는 전체 요율을 입력했을 때 표시됩니다.
원가와 비용 배분은 요율 없이도 계산됩니다. 수량·단가가 누락되면 원본 파일·행을 표시합니다.
새 실행가와 기존 견적 계산은 각각의 원본 기준을 유지합니다.

5. 생성 엑셀

실제 원본에 존재하는 평형별로 실행가 시트와 개별단가 시트를 만듭니다.
창 수에 맞게 행과 합계 범위가 바뀝니다.
외창 교체 합계는 외창만, 전체 교체 합계는 외창과 내창 모두를 포함합니다.
설치위치와 수량을 원본에서 가져오고, 원본 시공비 연결 번호를 AB열에 남깁니다.
외부 파일 링크를 제거하고 이 파일 안에서 계산되는 수식을 생성합니다.
원본 양식의 셀 서식과 열 너비를 재사용하고, 표 머리글과 유리사양은 줄바꿈합니다.
인쇄 영역은 새 행 수에 맞춰 설정하고 가로 한 페이지, 세로 자동 페이지를 사용합니다.
기존 현장 평면도·셀 메모·수동 페이지 나눔은 새 현장과 맞지 않아 복제하지 않습니다.
개별단가 인쇄 영역 밖의 동그라미 숫자와 표시 도구는 원본 그대로 각 시트에 복사합니다.
실행가 시트의 보호를 해제해 요율·비용·최종가격을 수정할 수 있습니다.
Excel에서 열 때 모든 수식이 다시 계산되도록 설정했습니다.
계산이 꺼진 Excel 환경이면 수식 > 계산 옵션 > 자동으로 바꾸고 Ctrl+Alt+F9를 누릅니다.

6. 기존 앱과 처리 환경

담당자 선택 방식과 기존 견적 작성·저장·조회·출력 코드를 유지했습니다.
기존 app.js의 변경은 새 화면을 화면 전환 목록에 추가한 한 곳입니다.
기존 데이터베이스, 가격표 파일과 견적 계산식을 수정하지 않았습니다.
이번 업로드본의 담당자 선택은 계정 로그인 기능과는 다릅니다. 실제 계정 로그인은 포함되지 않습니다.
실행가 ZIP은 브라우저에서 처리하며, 별도 서버·Python·LibreOffice 설치가 필요하지 않습니다.
ZIP은 20MB 이하, 압축 해제한 엑셀 전체는 60MB 이하, 평형당 창은 최대 500개입니다.

경계 사례(실제 다른 단지 자료가 아닌 시험 데이터):

아직 검증하지 못한 범위:

- 다른 아파트 단지의 실제 원본 자료

첨부된 예전 생성 결과물은 비교에만 사용했습니다.
시험용 요율을 실제 현장 값으로 설정하거나 함께 배포하지 않았습니다.

8. V61 생성 버튼 반응 수정

생성 버튼 바로 위에도 누락 항목·진행 상태·오류를 표시합니다.
원본 문제로 생성할 수 없는 경우에도 버튼을 누르면 사유를 보여줍니다.
입력값 수집과 검증 과정의 오류도 화면에 표시하도록 오류 처리 범위를 넓혔습니다.
생성 후 다운로드 버튼을 남겨 자동 다운로드가 시작되지 않아도 직접 받을 수 있습니다.
모의 DOM에서 실제 클릭 처리 함수를 실행해 첨부 ZIP의 엑셀 생성,
다운로드 링크, 누락 안내, 오류 안내와 버튼 복구를 검증했습니다.
실제 배포된 브라우저 조작은 아직 검증하지 못했습니다.

9. V61 변경사항

화면과 메뉴 이름을 '실행가 엑셀 파일 생성'으로 변경했습니다.
요율을 비워둬도 엑셀을 생성할 수 있으며 Excel에서 계속 수정할 수 있습니다.
화면 상단 '빈 실행가 양식 엑셀 다운로드' 버튼으로 실행가 양식.xlsx를 받습니다.
이 파일을 본사 단가표 폴더에 넣고 자재비·시공비와 함께 ZIP으로 압축하면 됩니다.
이전에 별도로 만들어진 실행가 결과 파일을 함께 넣지 마세요.

다운로드 양식은 첨부 원본의 표 구조와 서식을 사용합니다.
창 제품·규격·수량·가격·요율·외부 링크는 비워두고 할인율은 유지하고 부가시공비 입력값은 비웠습니다.
양식의 시트명에 관계없이 실제 입력 평형과 창 수로 결과 시트와 행을 생성합니다.

검증: 다운로드 양식을 ZIP에 넣어 33개 창의 요율을 전부 빈칸으로 생성했습니다.
수식 엔진에서 원가는 계산되고 판매금액은 빈칸으로 남는 것을 확인했습니다.
요율 한 개를 입력하면 해당 창 판매금액이 계산되고, 나머지를 모두 입력하면 합계가 표시됩니다.
전체 요율을 입력한 결과는 기존 검증 금액과 일치했습니다.

10. V61 Excel 복구 문제 수정

추가 서식의 alignment/protection 순서를 Excel XML 규격에 맞게 수정했습니다.
분할창 제거 후 남던 pane 선택 영역을 제거하고 정상 보기로 저장합니다.
빈 양식은 ○평, ○평_개별단가 두 시트만 제공하며 부가시공비는 비워둡니다.
기존 원본 양식과 공통 양식 모두에서 생성·XML 구조·수식 재계산을 검증했습니다.
실제 Microsoft Excel의 복구 안내 유무는 이 환경에서 확인하지 못했습니다.

11. V61 개별단가 표시·소계·테두리 수정

새 실행가 생성 모듈 execution-formulas.js도 함께 업로드해주세요.
압축 안의 전체 파일을 기존 저장소 루트에 올리면 필요한 파일이 모두 포함됩니다.

개별단가의 위치·제품명·유리사양·금액은 실행가 시트에 수식으로 연결합니다.
이번 버전은 수식과 계산 결과를 함께 저장하므로 재계산 전에도 값이 보입니다.
요율이 없을 때는 제품 정보와 원가만 표시하고 판매금액은 빈칸으로 둡니다.
Excel 자동 계산을 지정해 요율·위치·최종금액을 수정하면 연결값도 갱신됩니다.

발코니 창 사이의 FIX는 본사 품목 카테고리만으로 내창에 넣지 않고,
주변 일반 창의 묶음을 따라 배치합니다. 첨부 실행가와 같은 분류입니다.
단가·수량·창 및 유리 시공비는 본사 원본 값을 사용합니다.
테두리를 동일한 얇은 선으로 정리하고 소계 제목 A:G를 병합합니다.
소계는 연녹색, 전체 합계는 연파랑으로 구분합니다.
개별단가 표 밖에 복사되던 불필요한 셀과 선을 제거했습니다.

검증: 새로 첨부한 ZIP 안의 실행가와 같은 요율·할인율·비용을 적용하여

13. V63 모두 확인 및 개별단가 F열 자동 계산

생성 버튼 위에 모두 확인 체크를 추가했습니다. 전체 선택/해제가 가능합니다.
할인율·요율·비용을 바꾸면 해당 평형의 확인이 풀리고 모두 확인에도 반영됩니다.
개별단가 F열은 E열 × 0.85를 10만 원 단위로 반올림합니다.
수식: =IF(E20="","",ROUND(E20*0.85,-5))
창별 행과 외창/전체 합계 행 모두 같은 기준으로 계산합니다.
E열이 빈칸이면 F열도 빈칸이며 E열 변경 시 Excel에서 자동 재계산합니다.
예: 1,790,000원 × 0.85 = 1,521,500원 → 1,500,000원.
합계 F열도 왼쪽 합계 E열에 직접 0.85를 곱해 반올림하므로,
개별 행의 반올림된 F열 금액을 더한 값과 차이가 날 수 있습니다.
모두 확인 선택/해제 및 개별 확인과의 동기화, 기존 가격 대조,
빈칸과 반올림 계산, 생성 클릭과 기존 견적앱 모의 검증을 수행했습니다.
