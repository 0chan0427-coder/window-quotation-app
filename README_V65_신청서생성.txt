V65 신청서 엑셀 파일 생성

적용: 압축을 풀고 기존 GitHub 저장소에 업로드/덮어쓰기 후 Vercel 배포합니다.
V64 행사 현황 SQL을 이미 실행했다면 추가 SQL 작업은 없습니다. 아직 실행 전이면 supabase-migration-v64-events.sql을 한 번 실행해주세요.

메인 > 신청서 엑셀 파일 생성
1. 실행가에 요율을 입력하고 Excel에서 저장합니다.
2. 단지명(선택)과 실행가 .xlsx를 넣고 파일 확인을 누릅니다.
3. 평형별 외창/전체창 금액을 확인하고 신청서 생성/다운로드를 누릅니다.

금액: 개별단가 E열의 ‘창호 외부 교체 비용’과 ‘창호 전체 교체 비용’을 찾아 복사합니다. F열의 85% 계산 금액은 사용하지 않습니다.
금액이 비었거나 오류면 생성을 제한하며 요율 입력 후 저장을 안내합니다.
복사된 금액은 외부 파일 연결 수식이 아닌 숫자이므로 신청서 자체에서 수정할 수 있습니다. 실행가를 바꿨으면 신청서를 다시 생성해주세요.

첨부 예시의 평형 이름만 있는 시트(24/33/43평) 기준. 수정 시트/별도 - 시트 제외.
동·라인, 평면도, 추가상품 금액, 기타 추가비 숫자는 빈칸입니다. 로고와 복사할 번호 그림, 기본 문구, 표 서식, A4 세로 인쇄 영역은 유지합니다.
기존 양식에 없는 평형은 25평 이하 24평, 40평 미만 33평, 그 이상 43평 양식을 사용하고 평형 및 창 개수/금액을 바꿉니다.
일반적인 28T 등 상품 설명은 예시의 기본 문구를 유지하므로 현장별 변경사항은 Excel에서 확인/수정해주세요.
V64 행사 현황과 V63 실행가 생성은 유지합니다.
