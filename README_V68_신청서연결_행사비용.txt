V68 신청서 바로 연결 · 맨 위로 이동 · 행사 비용

적용 순서
1. Supabase SQL Editor에서 supabase-migration-v68-event-costs.sql 전체를 한 번 실행합니다.
   행사 현황을 처음 적용한다면 v64-events.sql을 먼저 실행해주세요.
2. 압축을 풀고 GitHub 기존 파일을 업로드/덮어쓰기합니다.
3. Vercel 배포 후 새로고침합니다.

실행가 → 신청서
실행가 생성 완료 후 다운로드 버튼 옆의 ‘이 실행가로 신청서 만들기’를 누르면 파일을 다시 선택하지 않고 연결합니다.
금액이 계산되어 있으면 평형별 합계 확인 후 신청서를 생성합니다.
요율이 비어 있다면 실행가 화면에서 입력 후 다시 생성하거나, Excel에서 요율을 입력·저장한 파일을 신청서 화면에서 선택합니다.
신청서 화면의 단지명은 직접 입력할 수 있습니다.

맨 위로 이동
모든 화면에서 아래로 300px 이상 내려가면 오른쪽 아래에 ‘↑ 맨 위로’ 버튼이 나타납니다.

행사 비용
행사 추가/수정 화면에서 비용 항목을 여러 개 추가합니다.
항목명, 금액(만원), 메모를 입력하고 저장합니다. 게시판비/자리비/구경집 비용/식비 등 항목명 직접 입력.
행사별 비용과 현재 조회 조건에 해당하는 입력된 비용 합계를 표시합니다.
비용 미등록은 ‘미등록’, 비용 0원 등록은 ‘0만원’으로 구분합니다.
계약금액과 도넛 기여율은 계약 실적 기준을 유지하며 비용을 차감하지 않습니다.
비용 내역은 팀 공유 Supabase에 행사 정보와 함께 저장합니다.

파일 연결, 비용 입력 검증/합계, 맨 위로 이동, 기존 견적·행사 기능 모의 검사 통과.
실제 Supabase 저장과 모바일 화면은 적용 후 확인해주세요.
