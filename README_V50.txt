V50 - LX Z:IN / 주식회사 도도 창호 견적 관리

추가사항
- 메인 화면에서만 담당자 이름 뒤에 “님”을 표시합니다. 담당자 선택 화면과 견적서 표기는 기존 표기를 유지합니다.
- 저장된 견적 검색: 현장명, 고객명, 연락처, 주소, 견적번호 + 상태 필터
- 기존 견적 상세에서 “견적 복사”로 창호 순서/요율/추가상품/조건을 유지한 새 견적 작성
- 견적 변경 이력 저장: 최초 저장/수정/삭제 시 담당자, 시각, 금액 전후 스냅샷
- 저장된 견적 목록 CSV(엑셀 호환) 내보내기
- 전체 견적 JSON 백업 저장 및 백업 복원
- 기존 V49의 계산/요율/순서 보존/견적서/아이콘/로고 이동 기능 유지

필수 DB 마이그레이션
- supabase-migration-v50.sql을 Supabase SQL Editor에서 1회 실행해야 변경 이력이 저장됩니다.
- 마이그레이션 전에도 나머지 기능은 사용할 수 있으며, 변경 이력 영역은 안내 문구로 표시됩니다.
