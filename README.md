# 창호 견적 관리 V26

V23을 기준으로 견적 관리 앱을 정리하고 V26 고객용 XLSX 스타일을 유지하면서 내부용 상세 견적을 별도 양식으로 분리한 버전입니다.

## 이번 버전 변경사항
- 내부용 상세 견적서는 고객용 XLSX와 분리
- 내부용에서 실측 가로×세로 / 적용 가로×세로를 명확하게 표시
- 내부용 자재비·시공비·항목별 합계 및 부가시공비 표시
- 고객용 견적서의 담당자 카드가 선택된 담당자 이름으로 동적으로 표시
- 담당자 전화번호도 STAFF 설정값을 통해 동적으로 표시
- 고객용 결제 기본값: 계약금 10% / 중도금 70% / 잔금 20%
- 결제 방법과 결제 비율을 고객용 견적서 하단에서 수정 가능
- 결제 비율 변경 시 계약금/중도금/잔금 금액 즉시 재계산
- 저장 시 payment_data에 비율과 금액을 함께 보관

## 담당자 전화번호
현재 제공된 명함 이미지에서 확인 가능한 한동균 팀장 번호만 `010-7415-0619`로 등록했습니다.
김민찬 책임과 김영찬 책임의 번호는 기존 파일/대화에서 확인되지 않아 빈 값으로 두었습니다. 번호를 확인하면 `app.js`의 STAFF 항목에 입력하면 견적서에 자동 반영됩니다.

## Supabase
기존 V26 마이그레이션을 사용합니다. `payment_data`가 없는 기존 견적은 고객용 견적서에서 자동으로 10/70/20 기본값을 사용합니다.


## V26 변경사항
- 고객용 견적서 상단을 승인 시안 기준으로 재배치: 명함을 상단 우측 독립 카드로 배치하고 견적 정보 표는 카드 아래 전체 폭으로 확장.
- 담당자 연락처 자동 적용: 한동균 팀장 010-7415-0619 / 김민찬 책임 010-8438-7469 / 김영찬 책임 010-5490-9662.
- 명함의 제2전시장 문구 삭제, 제1전시장 및 서울 주소만 표시.
- 방충망 표기 조건은 발코니창·복도창을 외창으로 보고 `AL 방충망`, 그 외 창 종류는 `-`로 표시.
