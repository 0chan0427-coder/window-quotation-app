# 창호 견적 관리 앱 V1

## 포함 기능
- Supabase 연결
- 견적 목록 조회
- 새 견적 작성
- 현장명, 고객명, 주소, 상태, 메모 저장
- 견적 상세 확인
- 모바일 반응형 화면

## 업로드 방법
1. 압축을 풉니다.
2. GitHub 저장소에서 Add file → Upload files를 선택합니다.
3. 압축 해제한 내부 파일을 모두 업로드합니다.
4. Commit changes를 누릅니다.

## 다음 버전
창호 항목, 실측 치수, 제품별 가격표 조회, 자동 계산, 고객용 PDF/이미지 견적서를 추가합니다.
